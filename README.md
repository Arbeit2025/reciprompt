# レシピ依頼プロンプトメーカー（reciprompt）

冷蔵庫の食材と条件を選ぶと、生成 AI（ChatGPT など）に貼るための「レシピ依頼文」を組み立ててくれるツールです。AI の API は使わず、依頼文の作成だけを行います。

## 使い方

1. 食材（カンマ区切り）、人数、気分（さっぱり／がっつり／時短／節約／ヘルシー）、系統（和／洋／中／エスニック／おまかせ）、補足を入力します。
2. 「依頼文を作る」を押すと、分量つき・手順つきで頼む形に整えた依頼文が表示されます。
3. コピーボタンでコピーして、使っている生成 AI に貼り付けてください。
4. よく使う食材の組み合わせは「食材セット」として名前つきで保存でき、次回は「読み込む」で呼び出せます（SQLite に保存、環境変数 `RECIPROMPT_DB` でパス変更可）。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- このツール自体はレシピを生成しません。生成 AI への依頼文を作るだけです。レシピの内容は貼り付け先の AI によります。
- 食材の在庫管理や栄養計算の機能はありません。
- コピーボタンは HTTPS または localhost で動作するクリップボード API を使います。使えない環境では依頼文を手動で選択してコピーしてください。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
